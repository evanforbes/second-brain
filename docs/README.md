# docs

Durable knowledge: the things that outlive any single test. Every `docs/` note uses `templates/doc.md` (or `templates/channel.md` for platform playbooks) and is trusted for 90 days after `last_verified`.

## Sections

- [channels](channels/README.md): one playbook per platform
- [creative](creative/README.md): testing method, naming, incumbents, learnings
- [measurement](measurement/README.md): attribution, incrementality, MMM, CAC math
- [budget](budget/README.md): allocation, pacing, decision log
- [conversion](conversion/README.md): app store, landing pages, offers
- [market](market/README.md): competitors and regulation
- [routines](routines/): how to run each routine
