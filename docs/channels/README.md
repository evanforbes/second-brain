# channels

One playbook per platform, built from `templates/channel.md`. Each is compiled from the platform's official help center and policies (crawled to `raw/channels/`, local only), aimed at Underdog, with source URLs. Specs and policies drift fast, so check before quoting one. Refresh with the `channel-docs` skill.

**Start with [[ad-policy-matrix]]:** which Underdog product (fantasy vs. prediction markets) can advertise where, and under what approvals.

## Channel jobs

Judge every channel against its job.

| Channel | Job | Measurement caveat |
|---|---|---|
| [[google]] | Intent capture | Brand cannibalization; iOS SKAN arrives up to 45 days late |
| [[meta]] | Demand creation | SRN self-attribution; AEM modeling; test the incremental attribution model |
| [[tiktok]] | Demand creation | Self-attributing network; engaged view-through; SKAN AEO needs 90+ installs a day |
| [[snapchat]] | Younger first-time audience | 28-day click default; 5-second views sent as clicks; judge on matured cohorts |
| [[reddit]] | High-intent communities | Small volume; the FTD goal is locked per ad group |
| [[x]] | Surgical, real-time moments | Small and noisy; read on incrementality |
| [[apple-search-ads]] | App Store intent capture | Brand-drift risk; age-targeted ad groups don't attribute (since Sep 2026) |
| [[liftoff]], [[moloco]], [[rzr]] | Programmatic DSPs: incremental reach that has to prove itself | View-through and engaged views inflate credit; check Protect360 |
