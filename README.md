# UA Second Brain

Evan's user acquisition knowledge base for Underdog Sports. Open it in Obsidian to read; work in it with Claude to write. The rules Claude follows are in [CLAUDE.md](CLAUDE.md).

## Where things live

| Folder | What goes there |
|---|---|
| `tests/` | One note per test: creative, offer, landing page, app store, experiment. Briefed tests sit in `backlog/`. |
| `docs/channels/` | One playbook per platform: TikTok, Meta, Snapchat, Google, Reddit, Apple Search Ads, Liftoff, Moloco, RZR. |
| `docs/creative/` | Testing method, naming taxonomy, incumbents, and the learnings index. |
| `docs/measurement/` | AppsFlyer, attribution, incrementality, MMM, CAC math. |
| `docs/budget/` | Allocation logic, pacing, and the decision log. |
| `docs/conversion/` | App store, landing pages, offers. |
| `docs/market/` | Competitors and the regulatory landscape. |
| `docs/glossary.md` | Every acronym and piece of shorthand, plus the tag list. |
| `meetings/` | COO 1:1, creative sync, team standup, channel rep calls. |
| `daily/`, `weekly/` | Daily rollups and the weekly channel review. |
| `templates/` | Start every note from one of these. |
| `raw/` | Gitignored drop zone for exports, screenshots, scraped docs. |
| `personal/` | Gitignored. Claude only writes here when you say "personal" or "private." |

## Things to say to Claude

- "We ran a creative test in campaign X. Pull the data. What won?"
- "Prep me for my COO 1:1."
- "Draft this week's channel review."
- "What did I do today?" / "EOD report" (once connectors are live)
- "Remember this: ..."
- "Audit my knowledge base" (once there are ~30 notes)

## Rules of thumb

- No real spend, CPFTD, or target figures in files yet; that waits for the work machine.
- No colleague names; roles only.
- Nothing is deleted; things get archived.
- Nothing is pushed to GitHub unless you ask.
