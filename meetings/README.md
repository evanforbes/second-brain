# meetings

Prep and notes for recurring meetings, from `templates/meeting.md`, named `YYYY-MM-DD-slug.md`. Append-only once written. Attendees by role, never by name.

Recurring: COO 1:1 (`coo-1-1`), creative sync (`creative-sync`), team standup (`team-standup`), channel rep calls (`channel-rep`).
