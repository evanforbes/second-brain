# tests

One note per test, from `templates/test.md`, named per [[naming-taxonomy]]. Types: creative, offer, landing-page, app-store, experiment. Every test runs against an incumbent and is judged on CPFTD first, then scale, CPI, IPM, CPM, CTR.

Lifecycle: `briefed` (in `backlog/`) → `live` → `read-out` → `scaled` or `killed` → `archived` (moved to `_archive/`). Tests usually turn around in under a week, so results older than 7 days get re-pulled before quoting. Each concluded test adds a line to [[learnings]].
